# 记忆 V2 验证

日期：2026-10-26；2026-10-27 按最终双服务所有权补充说明。

当前完成态由 Go control plane 持久化会话、账号记忆、引用和 run 终态；Python agent runtime 只消费 Go 构造的记忆快照并返回摘要或回答提案。本页测试数字是历史行为回归记录，不表示 Python 拥有业务记忆。

## 本次行为

长期记忆支持用户档案、表达偏好、业务背景。姓名默认长期保留，身份与组织默认 365 天有效、180 天复核，业务背景默认 90 天。未保存开关的账号默认关闭召回，已有明确设置保留。

个人问答使用有来源的字段值与当前会话声明，不需要远端模型生成姓名或职业。答案持久化对应记忆或消息来源，法规和混合问题继续进入原 Agent 与 Evidence QA 链路。

最终结果：Ruff、格式检查、mypy 通过；pytest **1041 passed, 1 skipped**。跳过的是默认关闭的外部 live RAG 测试。13 条 Evidence QA oracle 协议自检通过，属于协议检查，不代表真实模型准确率。

专项覆盖字段拆分、原话归属、复核、有效期、默认开关、当前条件优先、账号隔离、原子批量写入、删除与最终提交竞态，以及旧数据库迁移和备份。最终架构中这些业务写入与终态竞态由 Go 负责；Python 侧测试覆盖快照消费、摘要和 Agent 使用。

期间有一次完整检查的附件异步入库用例出现 `IntegrityError`；当时单独复现及最后完整检查均通过。后续 Go/Python 迁移回归稳定复现了首次并发初始化 `evidence_embedding_profile.singleton` 的主键竞争，并改为原子初始化后重新校验身份与维度，另加并发回归。

## 当前本地服务验证

开发服务已重启至 <http://127.0.0.1:8765>，首页与健康接口返回 HTTP 200，新页面提供用户档案字段和有效期选择。

对现有记录“我是马乐乐，是名学生”实际迁移验证：

- 拆为姓名“马乐乐”和身份“学生”，各自保留原话片段。
- 姓名 `expires_at=null`，身份 `retention_days=365`，设置复核时间。
- 迁移前后的所有非记忆表按行数与内容 SHA-256 校验一致。
- SQLite backup 文件已生成于 `data/backups/`。迁移没有覆盖已有账号召回开关。
- 通过真实本地 HTTP 请求，“我叫什么”回答“姓名：马乐乐”，“我的职业是什么”回答“当前身份 / 职业：学生”，均附 `memory` 类型引用与原话。

这些请求使用现有本地身份签发的临时认证 Cookie，没有重新执行 GitHub OAuth，也没有调用远端模型。请求产生了用于验证的会话记录；不据此宣称任意个人问题或向量语义召回已经通过。

## 当前边界

档案识别与个人问答采用明确规则和有限问题合同。未识别的表达可通过前端选择档案字段填写。业务背景仍为关键词召回，向量语义检索和真实模型的记忆使用效果评测尚未接入。
