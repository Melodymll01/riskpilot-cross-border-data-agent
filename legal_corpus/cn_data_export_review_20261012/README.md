## 优先审阅的版本要点

1. 《网络安全法》收录2025年修正后的全文，并保存修改决定。境内存储与出境评估条款现在是**第39条**，不能继续按旧版第37条引用。修正内容于2026-01-01施行，法末保留的2017年施行日期是原始施行日期。
2. 《数据出境安全评估办法》《个人信息出境标准合同办法》应与2024年《促进和规范数据跨境流动规定》合读，门槛、豁免及有效期不能直接沿用旧规则。
3. 《个人信息出境认证办法》自2026-01-01施行；2025年末认证依据标准另有变更公告，GB/T 46068-2025的实施日期为2026-03-01。
4. 安全评估申报使用第三版指南。2024年发布页同时包含评估指南第二版与标准合同备案指南第二版，二者不能一起简单删除或一起认定为最新。
5. 上海、北京、广东的“2025版”清单在2026年发布或扩大适用范围，版本名称不等于发布年份。地方负面清单只能按具体地域、行业、场景和数据项适用。
6. C06/C07是2015年同一国际合作研究事件的两个处罚主体，不能重复统计为独立事件；其处罚依据是当时的暂行办法。
