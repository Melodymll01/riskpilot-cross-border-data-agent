    欢迎使用数智合规

    面向数据出境法规的对话式合规助手。Agent 会自主调用工具检索法条、研判证据并给出可追溯的回答。

    答案基于法规检索 + 工具调用，可能仍有误，请以官方文本为准。

    📚 知识库

    Agent 在检索时会引用这里的语料。任何用户都可上传/删除自己的私人文档；管理员可维护公共库与他人文档。

    — 文档
    — chunk
    🔒 当前以只读模式查看知识库；上传 / 删除需管理员权限。
    📄 上传文件
    支持 PDF / TXT / DOCX；最大 50 MB。默认上传到「我的」私人库。
    🌐 采集网页
    仅支持 http / https 协议的公开页面。默认采集到「我的」私人库。
    准备就绪
    类型 归属 source_name 标题 分类 chunk 数 操作

    📜 审计日志

    记录管理员在知识库上的写操作（上传 / 采集 / 删除）。只读、不可篡改。
